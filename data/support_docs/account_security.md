# Account Security

## Password Reset

Users can reset their password from the sign-in page by selecting Forgot Password. Password reset links expire after 30 minutes and can be used only once.

## Multi-Factor Authentication

Multi-factor authentication is available on Pro and Enterprise plans. Workspace admins can require MFA for all users from Settings > Security. Users who lose access to their authenticator app must contact a workspace admin for recovery.

## Session Management

Users can view and revoke active sessions from Account > Security > Active Sessions. Admins can revoke all sessions for a user when suspicious activity is detected.

## SSO

Single sign-on is available only on Enterprise plans. The platform supports SAML 2.0 identity providers. SSO enforcement can be enabled after at least one admin has successfully signed in through the identity provider.
