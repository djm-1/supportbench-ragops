# Data Retention and Privacy

## Deleted Workspaces

Deleted workspaces enter a 30-day recovery window. During this period, owners can request restoration. After the recovery window ends, production data is permanently deleted from active systems.

## Backups

Encrypted backups are retained for 35 days. Backup deletion follows the normal backup rotation schedule and cannot be accelerated for individual workspaces.

## Data Export

Workspace owners can export workspace data from Settings > Data Export. Exports include projects, comments, automation logs, and billing metadata. Exports do not include secrets, API token values, or deleted user passwords.

## Regional Storage

Enterprise customers can request regional data storage during onboarding. Region changes after onboarding require a migration window scheduled with support.
