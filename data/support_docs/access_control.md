# Access Control

## Roles

The platform supports Owner, Admin, Member, and Viewer roles. Owners manage billing and workspace deletion. Admins manage users and settings. Members can create and edit projects. Viewers can read project data but cannot edit it.

## Project Permissions

Project-level permissions can restrict access to specific projects on Pro and Enterprise plans. Free plan projects are visible to all workspace members.

## Guest Users

Guest users are available on Enterprise plans. Guests can access only the projects explicitly shared with them and cannot access billing, security, or workspace-wide settings.

## Audit Logs

Audit logs are available on Enterprise plans and record user invites, role changes, billing changes, API token creation, and security setting updates.
