# Integrations

## Slack Integration

The Slack integration is available on Pro and Enterprise plans. Workspace admins can connect Slack from Settings > Integrations. Notifications can be configured per project.

## Salesforce Integration

The Salesforce integration is available on Enterprise plans. It requires OAuth authorization from a Salesforce admin and can sync account, contact, and opportunity data.

## Calendar Integration

Google Calendar and Microsoft Outlook Calendar integrations are available on Pro and Enterprise plans. Calendar sync runs every 15 minutes.

## Integration Failures

If an integration fails authorization, the workspace admin receives an email and the integration status changes to Action Required. Most authorization failures are fixed by reconnecting the integration.
